<h2 id="about">About</h2>
This is a simple platformer/puzzle game made for the school "Alfa-college". This game was developed in Unity 6000.0.58F2 with DotNet version 9.0.
This game was made so that new students can learn a bit about the course "Software-development" in a more intresting manner. It is written to run on a raspbery pi ?.
